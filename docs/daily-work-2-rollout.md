# Bevezetési sorrend

1. Prioritási motor és adapterek integrálása a szaktanácsadói munkanapba.
2. Kritikus figyelmeztetési sáv bekötése.
3. Gazdálkodói napi nézet azonos prioritási logikával.
4. Munkakiosztás állapotgépének bekötése.
5. Végrehajtási bizonyíték ellenőrzése.
6. Automatikus utánkövetés szerveroldali létrehozással.
7. Regresszióteszt: feladatok, szemlék, műveletek, jóváhagyások, jelzések, RLS és szerepkör-szétválasztás.
8. Preview ellenőrzés, majd csak zöld állapot esetén merge.
